# CURRENCY-CONVERTOR-WEB-APPLICATION
The app fetches live exchange rates from a public API such as exchangerate.host, ensuring accurate and up-to-date conversions. The UI includes two dropdown menus for currency selection, an input field for the amount, and a convert button. The result is displayed dynamically below the form. 🌍 Currency Converter Web Application

A simple, responsive currency converter that allows users to convert amounts between different currencies in real-time using live exchange rates. Built using **HTML**, **CSS**, Bootstrap, and JavaScript, this project demonstrates API integration and a clean frontend UI.

## ✨ Features

- 🔄 Real-time currency conversion
- 🌐 Fetches live exchange rates from [exchangerate.host](https://exchangerate.host)
- 📱 Mobile-friendly responsive design using Bootstrap
- 🔽 Dropdown menus for selecting source and target currencies
- ✅ Input validation and basic error handling
- 💡 Easy to use and beginner-friendly

## 🧰 Tech Stack

- **Frontend:** HTML, CSS, Bootstrap, JavaScript
- **API:** [exchangerate.host](https://exchangerate.host) or any other public exchange rate API
